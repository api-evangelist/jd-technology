# JD Technology (JD Cloud)

> JD Technology Group (京东科技集团) is the cloud and technology subsidiary of JD.com, serving government, financial institutions, and enterprises. Its developer surface is JD Cloud (京东云), whose OpenAPI exposes compute, storage, database, networking, AI, and security services. Integration is via access-key / secret-key signed REST calls to per-service endpoints (<service>.jdcloud-api.com), with first-party SDKs and the jdc CLI. This file is generated by the API Evangelist enrichment pipeline from JD Technology's public developer surfaces.
